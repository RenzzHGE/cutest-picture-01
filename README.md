# cutest-picture-01

A baby pink axolotl smiling in a pastel-blue teacup, a heart of steam
rising above it — one clear adorable moment, soft round shapes, big bright
eyes, readable at 300 pixels wide. Entry for make.fun's cutest-picture-01.

## Run

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

`main.ts` copies `entry.png` to `/output/entry.png` byte for byte, so both
grading runs write the same file.
